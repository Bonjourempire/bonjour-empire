BONJOUR EMPIRE — SITE STATIQUE AVEC CSS EXTERNE

CONTENU
- index.html : accueil
- apropos.html, activites.html, afrikarts.html, cartes.html, contact.html : pages secondaires
- assets/css/style.css : feuille de style principale
- assets/js/main.js : menu mobile et année automatique

INSTALLATION SUR GITHUB
1. Décompressez ce ZIP.
2. Dans votre dépôt GitHub, ouvrez Add file > Upload files.
3. Ouvrez le dossier extrait et téléversez les fichiers ET le dossier assets (pas le dossier parent).
4. Les fichiers doivent se trouver à la racine du dépôt : index.html, apropos.html, assets/...
5. Si GitHub demande de remplacer index.html ou d'autres fichiers, vérifiez que vous avez bien téléchargé une sauvegarde du dépôt.
6. Commit directement dans la branche main.
7. Dans Settings > Pages, vérifiez Deploy from a branch, branche main, dossier /(root).

IMPORTANT
- Le lien CSS utilisé dans toutes les pages est relatif : assets/css/style.css
- Le lien JavaScript est : assets/js/main.js
- Le site est statique et compatible GitHub Pages.
- Le formulaire de contact n'est pas inclus et il n'y a pas de paiement en ligne.
- Les coordonnées et les liens sociaux peuvent être modifiés dans les fichiers HTML.
- Le site utilise Google Fonts si une connexion Internet est disponible ; des polices système prennent le relais sinon.
